AI-Research-Paper-Assistant

I Created a folder for the project named “AI-Research-Paper-Assistant” and then created a virtual environment for the project to be run, so it doesn’t depend on the global python run environment and doesn’t get any conflict, we use command “python -m venv .venv” where we are telling python to install module venv, which is a built in module into folder venv, we could have named it anything but using venv is norm and the . before the name makes it hidden in folder.

Now that we have created a virtual environment we have to tell the terminal to use it  for that we use command “source .venv/bin/activate” and atlast after terminal we setup this vertual environment for editor, by selecting it in “Python: Select Interpreter”.
